# 设计模式

总体来说设计模式分为三大类：

**创建型模式**，共五种：工厂方法模式、抽象工厂模式、单例模式、建造者模式、原型模式。

**结构型模式**，共七种：适配器模式、装饰器模式、代理模式、外观模式、桥接模式、组合模式、享元模式。

**行为型模式**，共十一种：策略模式、模板方法模式、观察者模式、迭代器模式、责任链模式、命令模式、备忘录模式、状态模式、访问者模式、中介者模式、解释器模式。

# 创建型模式

## 单例模式（Singleton）

**意图**：保证一个类型在进程中只有一个实例，并提供全局访问入口。

**适用场景**：进程级配置、只需初始化一次的注册表。数据库连接池通常由驱动管理，业务代码只需复用连接池，不要把“单例”误解成“单连接”。

```go
package config

import "sync"

type Config struct {
        Port int
}
var (
        once     sync.Once
        instance *Config
)
func Get() *Config {
        once.Do(func() {
                instance = &Config{Port: 8080}
        })
        return instance
}
```

**注意**：全局单例会隐藏依赖，使测试互相影响。Go 项目通常更推荐在 `main` 中创建实例，再通过构造函数注入。

## 工厂方法模式（Factory Method）

**意图**：定义创建对象的接口，由具体实现决定创建哪种对象。

**适用场景**：根据配置创建不同消息发布器、存储实现或通知渠道。

```go
type Publisher interface {
        Publish(message string) error
}

type PublisherFactory interface {
        Create() Publisher
}

type KafkaFactory struct{}

func (KafkaFactory) Create() Publisher {
        return &KafkaPublisher{}
}
```

若分支不多，也常用更简单的 switch 写法（简单工厂，不属于 GoF 的工厂方法）：

```go
func NewPublisher(kind string) (Publisher, error) {
        switch kind {
        case "kafka":
                return &KafkaPublisher{}, nil
        case "memory":
                return &MemoryPublisher{}, nil
        default:
                return nil, fmt.Errorf("不支持的发布器类型: %s", kind)
        }
}
```

## 抽象工厂模式（Abstract Factory）

**意图**：创建一组有关联、需要配套使用的对象，而不暴露具体类型。

**适用场景**：为不同运行环境成套创建 Repository、Cache 和 Publisher。

```go
type InfrastructureFactory interface {
        NewArticleRepository() ArticleRepository
        NewCommentRepository() CommentRepository
}

type MySQLFactory struct {
        db *sql.DB
}

func (f MySQLFactory) NewArticleRepository() ArticleRepository {
        return &MySQLArticleRepository{db: f.db}
}

func (f MySQLFactory) NewCommentRepository() CommentRepository {
        return &MySQLCommentRepository{db: f.db}
}
```

**与工厂方法的区别**：工厂方法通常创建一种产品；抽象工厂创建一整套相互兼容的产品。

## 建造者模式（Builder）

**意图**：把复杂对象的构造过程拆成多个步骤，并集中处理默认值和校验。

**适用场景**：测试数据、复杂查询条件、包含大量可选配置的对象。

```go
type Article struct {
        Title   string
        Content string
        Tags    []string
        Status  string
}

type ArticleBuilder struct {
        article Article
}

func NewArticleBuilder(title string) *ArticleBuilder {
        return &ArticleBuilder{article: Article{Title: title, Status: "draft"}}
}

func (b *ArticleBuilder) Content(content string) *ArticleBuilder {
        b.article.Content = content
        return b
}

func (b *ArticleBuilder) Tags(tags ...string) *ArticleBuilder {
        b.article.Tags = append([]string(nil), tags...)
        return b
}

func (b *ArticleBuilder) Build() (Article, error) {
        if b.article.Title == "" {
                return Article{}, errors.New("文章标题不能为空")
        }
        return b.article, nil
}
```

## 原型模式（Prototype）

**意图**：复制已有对象来创建新对象，避免重复执行复杂初始化。

**适用场景**：从模板创建文章、复制复杂配置、生成测试对象。

```go
type ArticleTemplate struct {
        Title string
        Tags  []string
        Meta  map[string]string
}

func (a ArticleTemplate) Clone() ArticleTemplate {
        clone := a
        clone.Tags = append([]string(nil), a.Tags...)
        clone.Meta = make(map[string]string, len(a.Meta))
        for key, value := range a.Meta {
                clone.Meta[key] = value
        }
        return clone
}
```

# 结构型模式

## 适配器模式（Adapter）

**意图**：将已有接口转换为调用方需要的接口。

**适用场景**：对接第三方 SDK、旧系统、DDD 防腐层。

```go
type HotCounter interface {
        Increment(articleID uint, score int) error
}

type RedisClient struct{}

func (RedisClient) ZIncrBy(key string, score float64, member string) error {
        return nil
}

type RedisHotCounter struct {
        client RedisClient
}

func (a RedisHotCounter) Increment(articleID uint, score int) error {
        return a.client.ZIncrBy("article:hot", float64(score), strconv.FormatUint(uint64(articleID), 10))
}
```

## 桥接模式（Bridge）

**意图**：把高层抽象和底层实现拆开，使两个维度能够独立扩展。

**适用场景**：通知类型与发送渠道分别变化，例如“评论通知/审核通知”与“邮件/短信”。

```go
type Sender interface {
        Send(receiver, content string) error
}

type Notification struct {
        sender Sender
}

func (n Notification) CommentCreated(receiver string) error {
        return n.sender.Send(receiver, "收到一条新评论")
}

type EmailSender struct{}

func (EmailSender) Send(receiver, content string) error {
        return nil
}
```

## 组合模式（Composite）

**意图**：把对象组织成树，并让调用方用同一种方式处理叶子节点和组合节点。

**适用场景**：评论树、菜单、组织结构、文件目录。

```go
type CommentNode interface {
        Count() int
}

type Comment struct{}

func (Comment) Count() int { return 1 }

type CommentGroup struct {
        children []CommentNode
}

func (g CommentGroup) Count() int {
        total := 0
        for _, child := range g.children {
                total += child.Count()
        }
        return total
}
```

## 装饰器模式（Decorator）

**意图**：在不修改原对象的情况下，动态叠加功能。

**适用场景**：缓存、日志、指标、重试、权限检查。

```go
type ArticleQuery interface {
        Find(id uint) (Article, error)
}

type CachedArticleQuery struct {
        next  ArticleQuery
        cache Cache
}

func (q CachedArticleQuery) Find(id uint) (Article, error) {
        if article, ok := q.cache.Get(id); ok {
                return article, nil
        }
        article, err := q.next.Find(id)
        if err == nil {
                q.cache.Set(id, article)
        }
        return article, err
}
```

## 外观模式（Facade）

**意图**：为复杂子系统提供一个简单、稳定的入口。

**适用场景**：应用服务协调仓储、消息、缓存和领域对象完成一个用例。

```go
type PublishArticleService struct {
        articles ArticleRepository
        events   EventPublisher
        cache    ArticleCache
}

func (s PublishArticleService) Publish(ctx context.Context, id uint) error {
        article, err := s.articles.Find(ctx, id)
        if err != nil {
                return err
        }
        if err := article.Publish(); err != nil {
                return err
        }
        if err := s.articles.Save(ctx, article); err != nil {
                return err
        }
        s.cache.Delete(id)
        return s.events.Publish(ArticlePublished{ArticleID: id})
}
```

## 享元模式（Flyweight）

**意图**：共享大量细粒度对象中的不变状态，以减少内存占用。

**适用场景**：大量对象共享标签样式、权限定义、解析后的模板等数据。

```go
type TagStyle struct {
        Color string
        Icon  string
}

type TagStyleFactory struct {
        styles map[string]*TagStyle
}

func NewTagStyleFactory() *TagStyleFactory {
        return &TagStyleFactory{styles: make(map[string]*TagStyle)}
}

func (f *TagStyleFactory) Get(name string) *TagStyle {
        if style, ok := f.styles[name]; ok {
                return style // 已存在则直接复用，避免重复创建
        }
        style := &TagStyle{Color: "gray", Icon: "tag"}
        f.styles[name] = style
        return style
}
```

## 代理模式（Proxy）

**意图**：使用替代对象控制对真实对象的访问。

**适用场景**：远程调用、懒加载、权限控制、限流。

```go
type ArticleService interface {
        Delete(ctx context.Context, articleID, operatorID uint) error
}

type AuthorizedArticleService struct {
        next ArticleService
        acl  AccessControl
}

func (s AuthorizedArticleService) Delete(ctx context.Context, articleID, operatorID uint) error {
        if !s.acl.CanDelete(operatorID, articleID) {
                return errors.New("无权删除该文章")
        }
        return s.next.Delete(ctx, articleID, operatorID)
}
```

# 行为型模式

## 责任链模式（Chain of Responsibility）

**意图**：让多个处理器依次处理请求，每个处理器可以继续传递或终止流程。

**适用场景**：HTTP 中间件、鉴权、参数校验、内容审核。

```go
type Handler func(ctx context.Context, req Request) error

type Middleware func(next Handler) Handler

func ValidateContent(next Handler) Handler {
        return func(ctx context.Context, req Request) error {
                if strings.TrimSpace(req.Content) == "" {
                        return errors.New("评论内容不能为空")
                }
                return next(ctx, req)
        }
}

func Authenticate(next Handler) Handler {
        return func(ctx context.Context, req Request) error {
                if req.UserID == 0 {
                        return errors.New("用户未登录")
                }
                return next(ctx, req)
        }
}
```

## 命令模式（Command）

**意图**：把一次操作封装成对象，以支持排队、记录、重试或撤销。

**适用场景**：任务队列、批处理、操作审计。

```go
type Command interface {
        Execute(ctx context.Context) error
}

type PublishArticleCommand struct {
        articleID uint
        service   ArticlePublisher
}

func (c PublishArticleCommand) Execute(ctx context.Context) error {
        return c.service.Publish(ctx, c.articleID)
}

type CommandBus struct{}

func (CommandBus) Dispatch(ctx context.Context, command Command) error {
        return command.Execute(ctx)
}
```

## 解释器模式（Interpreter）

**意图**：为简单语言定义语法，并解释执行表达式。

**适用场景**：简单搜索表达式、权限规则、过滤条件。

```go
type Expression interface {
        Match(article Article) bool
}

type StatusExpression struct {
        status string
}

func (e StatusExpression) Match(article Article) bool {
        return article.Status == e.status
}

type AndExpression struct {
        left  Expression
        right Expression
}

func (e AndExpression) Match(article Article) bool {
        return e.left.Match(article) && e.right.Match(article)
}
```

## 迭代器模式（Iterator）

**意图**：在不暴露集合内部表示的情况下顺序访问元素。

**适用场景**：分页查询、流式读取大数据集、自定义树遍历。

```go
type ArticleIterator interface {
        Next(ctx context.Context) (Article, bool, error)
}

type SliceIterator struct {
        articles []Article
        index    int
}

func (i *SliceIterator) Next(_ context.Context) (Article, bool, error) {
        if i.index >= len(i.articles) {
                return Article{}, false, nil
        }
        article := i.articles[i.index]
        i.index++
        return article, true, nil
}
```

## 中介者模式（Mediator）

**意图**：让多个对象通过中介者协作，减少对象之间的网状依赖。

**适用场景**：应用服务编排、事件总线、聊天室、复杂 UI 组件协作。

```go
type CommentMediator struct {
        comments CommentRepository
        hot      HotCounter
        events   EventPublisher
}

func (m CommentMediator) CommentCreated(ctx context.Context, comment Comment) error {
        if err := m.hot.Increment(comment.ArticleID, 1); err != nil {
                return err
        }
        return m.events.Publish(CommentCreated{CommentID: comment.ID})
}
```

## 备忘录模式（Memento）

**意图**：在不暴露对象内部细节的情况下保存状态，并在需要时恢复。

**适用场景**：草稿历史、编辑撤销、配置回滚。

```go
type ArticleSnapshot struct {
        Title   string
        Content string
        Status  string
}

func (a Article) Snapshot() ArticleSnapshot {
        return ArticleSnapshot{Title: a.Title, Content: a.Content, Status: a.Status}
}

func (a *Article) Restore(snapshot ArticleSnapshot) {
        a.Title = snapshot.Title
        a.Content = snapshot.Content
        a.Status = snapshot.Status
}
```

## 观察者模式（Observer）

**意图**：一个对象发生变化时，通知多个订阅者。

**适用场景**：领域事件、消息队列、缓存失效、通知与审计。

```go
type EventHandler interface {
        Handle(ctx context.Context, event ArticlePublished) error
}

type EventBus struct {
        handlers []EventHandler
}

func (b *EventBus) Subscribe(handler EventHandler) {
        b.handlers = append(b.handlers, handler)
}

func (b EventBus) Publish(ctx context.Context, event ArticlePublished) error {
        for _, handler := range b.handlers {
                if err := handler.Handle(ctx, event); err != nil {
                        return err
                }
        }
        return nil
}
```

## 状态模式（State）

**意图**：把不同状态下的行为封装起来，使对象行为随状态改变。

**适用场景**：文章草稿、已发布、已归档等状态流转。

```go
type ArticleState interface {
        Publish(article *Article) error
        Name() string
}

type DraftState struct{}

func (DraftState) Publish(article *Article) error {
        article.state = PublishedState{}
        return nil
}

func (DraftState) Name() string { return "draft" }

type PublishedState struct{}

func (PublishedState) Publish(_ *Article) error {
        return errors.New("文章已经发布")
}

func (PublishedState) Name() string { return "published" }
```

## 策略模式（Strategy）

**意图**：封装一组可互换的算法，让调用方可以按场景选择。

**适用场景**：热度算法、排序规则、折扣算法、密码编码器。

```go
type HotScoreStrategy interface {
        Calculate(likes, comments uint, publishedAt time.Time) float64
}

type RecentFirst struct{}

func (RecentFirst) Calculate(likes, comments uint, publishedAt time.Time) float64 {
        ageHours := time.Since(publishedAt).Hours() + 1
        return float64(likes*2+comments*3) / ageHours
}

type HotService struct {
        strategy HotScoreStrategy
}

func (s HotService) Score(article Article) float64 {
        return s.strategy.Calculate(article.Likes, article.Comments, article.PublishedAt)
}
```

## 模板方法模式（Template Method）

**意图**：定义算法骨架，把部分步骤交给具体实现。

**适用场景**：导入流程、内容发布流程、统一的数据处理管道。

Go 没有继承，通常使用组合和函数实现模板方法：

```go
type PublishHooks struct {
        Validate func(Article) error
        Persist  func(context.Context, Article) error
        Notify   func(context.Context, Article) error
}

func Publish(ctx context.Context, article Article, hooks PublishHooks) error {
        if err := hooks.Validate(article); err != nil {
                return err
        }
        if err := hooks.Persist(ctx, article); err != nil {
                return err
        }
        return hooks.Notify(ctx, article)
}
```

## 访问者模式（Visitor）

**意图**：在不修改稳定数据结构的前提下，为其增加新的操作。

**适用场景**：AST、文档节点、规则树，需要不断增加导出、统计、校验等操作。

```go
type Node interface {
        Accept(visitor Visitor)
}

type TextNode struct {
        Text string
}

func (n TextNode) Accept(visitor Visitor) {
        visitor.VisitText(n)
}

type ImageNode struct {
        URL string
}

func (n ImageNode) Accept(visitor Visitor) {
        visitor.VisitImage(n)
}

type Visitor interface {
        VisitText(TextNode)
        VisitImage(ImageNode)
}
```
