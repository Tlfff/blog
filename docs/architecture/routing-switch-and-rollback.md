# 路由开关与回滚

## 1. 路由开关

统一入口读取三个服务的 `services/*/config.yaml`：

```yaml
enabled: true
```

- `enabled: true`：统一入口通过 gRPC 调用该服务。
- `enabled: false`：统一入口拒绝启动并提示先确认服务健康，避免把请求打进未就绪的服务。

## 2. 流量切换顺序

1. 先启动并探活三个服务（gRPC health）。
2. 灰度开启 `enabled`，先验证只读接口（列表、详情、热榜、通知）。
3. 再验证写接口（注册、评论、点赞、文章写操作）。
4. 全部通过后保持新路由；异常时按回滚流程处理。

## 3. 回滚流程

- 写请求回滚：先将 `enabled` 改为 `false` 或回退网关镜像，停止新服务写入。
- 只读请求回滚：直接回退网关镜像即可，读操作无副作用。
- 回滚期间旧单体实现保留（`blog-server` 镜像的 `server`/`grpc` 命令），切换回旧实现后观察数据一致性。
- 禁止新老实现同时处理写请求，避免双写冲突。
